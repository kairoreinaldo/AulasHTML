HTML

Html é uma linguagem que desenvolve sites na web, utilizando o vscode voce desenvolve essa linguagem, a mesma é como o esqueleto do site, ou seja lá voce desenvolve textos, formatos, expansividade.

CSS

Já o CSS é a beleza do site, a estilização,é uma linguagem para desenvolver sites tambem utilizando o vscode, em base em dar vida, cor e modernidade em cima do que foi constuido no html.

JavaScript

Já o JS é onde entra os dados do usuario com o servidor do site, como: loguin, senha, lá podemos desenvolver o banco de dados da relação usuario e servidor, ou servidor e banco de dados, é o cerebro do sistema
